# Mintdown v0.4.1 — Windows 预览版

首个公开发布的 Mintdown 安装程序。面向 Windows x64，提供本地 Markdown 可视/源码编辑、多标签、大纲、图片资源管理及 HTML/PDF 导出；PDF 保留标题书签。

大纲和文档标签采用已确认的 compact 高亮规则；标准与紧凑密度共享背景、字重和 Hover 行为，密度仅保留原有尺寸差异。

## 安装

- 下载 `Mintdown_0.4.1_x64-setup.exe`，先按 `SHA256SUMS.txt` 核验。
- NSIS 当前用户安装，安装目录可选；保持既有稳定应用身份及设置目录。
- 安装后不需要 Rust、Cargo、Node.js 或本地开发服务器。
- 需要 Microsoft WebView2；缺少运行时时引导程序可能需要联网。
- 不强制修改用户为 `.md` 选择的默认应用。

## 已知限制
